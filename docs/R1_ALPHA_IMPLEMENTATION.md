# R1 실제 콘텐츠와 일일 정원 흐름

이 기록은 25개 알파 단계의 이력이다. 현재 상태는 [R1 60개 연속 진행 구현](R1_COMPLETE_ALPHA_IMPLEMENTATION.md)을 따른다.

2026-10-11 기준 R1 C01 10개, C02 S01부터 S05까지 5개, C04 복습 10개를 내부 알파로 구현했다. 실제 콘텐츠 25개와 일일 추천, 최초 완료 복원, 중단 및 재시작을 연결했다. 전체 캠페인 420개 중 나머지 395개는 실행 경로에서 차단한다. APK 배포 및 실제 기기 검증은 별도 단계다.

## 콘텐츠 범위

| 구간 | 개수 | 역할 |
| --- | ---: | --- |
| R1 C01 | 10 | 두 수량 합치기, 남은 수, 묶음, 배열, 나누기 등 기본 관계 |
| R1 C02 S01부터 S05 | 5 | 기본 관계를 부분식과 혼합 연산으로 연결 |
| R1 C04 | 10 | C01 S06부터 S10, C02 S01부터 S05의 독립 의미 변형 |

각 문제에는 실제 한국어 문장, 정답 AST, 같은 표시값도 구분하는 고유 토큰 manifest, 관찰 및 관계 및 부분식의 세 힌트, 오개념 피드백, 두 단계 이상의 풀이, 전이 문제와 시각 자료 설명이 있다. C04는 숫자나 명사만 바꾸지 않고 관계 질문, 문맥 또는 표현을 바꿔 독립 변형 조건을 검증한다.

`regionalCampaign`은 420개 설계 원본을 유지한다. `initialCampaign`은 그 위에 실제 문제를 적용한 현재 실행 카탈로그다. 기존 C01부터 C03의 stage ID, skill ID, puzzle ID, seed와 fixture ID는 보존했다. 개발용 `4×3+2` 체험은 별도 회귀용으로 남기고 캠페인 완료와 섞지 않는다. 실제 C02 S05는 별도의 캠페인 콘텐츠와 검증 fixture를 사용한다.

25개 각각에 5×5와 6×6 결정론적 보드를 등록했다. 시작 숫자와 봉인된 2개 또는 3개의 필수 조각을 구분하며 사용자는 자유롭게 인접 교환한다. 현재 보드 기준 힌트는 검증된 발굴 경로와 단순 매치 안내를 구분한다. 수학 힌트와 퍼즐 경로 힌트도 별도로 기록한다.

이동 예산은 solver 경로를 기준으로 설정한 내부 알파 값이다. 사람 플레이와 10~20가족 관찰로 보정하기 전에는 베타 난도 또는 학습 효과가 검증되었다고 해석하지 않는다. 단층 봉인만 실행되며, 2층 봉인과 직선 파워 등은 아직 구현하지 않았다.

## 화면과 완료 흐름

`월드맵 → 일일 복습 또는 다음 탐험 → 스테이지 안내 → 발굴과 식 조립 → 결과와 해설 → 열린 정원 복원 → 지역 정원`

월드맵에는 기억의 씨앗, 오늘의 탐험, 정원 돌보기 세 추천이 있다. 계산의 평원은 C01, C02, 복습 탭으로 실제 25개만 표시한다. 미작성 395개를 플레이 목록으로 노출하지 않는다. 현재 새 콘텐츠를 전부 완료하면 오늘의 탐험을 비활성화하며 완료한 S01을 새 스테이지처럼 반복 추천하지 않는다. 지역 목록에서 무료 재도전은 가능하다.

꿈의 정원의 퍼즐과 정원 진행 분리를 참고하되, KVM의 책임은 세 가지로 나눈다. 발굴 엔진은 조각을 얻고, 수학 엔진은 문장에 맞는 관계와 AST를 검증하고, 완료 서비스는 영수증으로 캠페인과 정원을 갱신한다. 발굴과 수학은 가로 화면의 별도 영역이며 결과와 정원은 별도 화면이다. 매치만 완료한 상태에서는 캠페인 완료나 복원 보상을 지급하지 않는다.

완료 별 1개는 보장한다. 수학 별과 탐색 별은 선택 목표이며 힌트를 써도 다음 스테이지와 복원을 막지 않는다. 같은 `attemptId`의 완료 재전달은 기존 영수증을 반환하므로 별, 일일 기록과 복원 지점이 중복 지급되지 않는다.

## 매일 복습과 다음 탐험

`DailyRouteService`는 학습 ticket과 달력 날짜를 구분한다. 기존 학습 ticket의 도래 기준은 완료 스테이지 수이며, 일일 연습은 로컬 달력 날짜다. 실제 시계나 날짜를 변경하지 않고 주입한 시간으로 다음 날 테스트한다.

1. 오늘 복습을 아직 하지 않았다면 도래한 ticket 중 실제 실행 가능한 독립 변형을 찾는다. 오래된 ticket에 맞는 문제가 없다고 다른 ticket의 복습까지 가리지 않는다.
2. 도래한 독립 변형이 없으면 이전 날짜에 완료한 문제로 일일 연습을 추천한다. 열려 있는 C04 변형을 단순 동일 문제 재연습보다 우선한다.
3. 일일 연습은 도래하지 않은 ticket을 소비하지 않으며 지연 독립 복습으로 자동 인정하지 않는다. 같은 문제를 다시 맞힌 것만으로 독립 변형 성공이 늘어나지 않는다.
4. 오늘 복습을 완료하면 추천 카드는 완료 상태가 된다. 지역 화면의 자유로운 재도전은 계속 가능하다.
5. 오늘의 탐험은 미완료이며 실행 가능한 코어 스테이지를 추천한다. 복습을 건너뛰어도 주 경로는 막히지 않는다.

C04는 대응 원본을 실제로 완료한 후 열린다. 저장에 잠금 해제 ID만 잘못 들어 있더라도 원본 미완료 상태에서는 완료 처리할 수 없다. C04는 C03 이후만 기다리는 심화 경로와 달리 이번 내부 알파의 source-linked 복습 진입도 제공한다. 다음 리전의 정식 개방은 기존 C03 S10 규칙을 유지하며 이번 25개만으로 R2가 열리지는 않는다.

최근 7일 활동은 달력 날짜로 계산한다. 연속 출석 손실, 생명, 대기, 광고, 결제 또는 알림을 추가하지 않았다. 매일 자동 개발 작업을 예약한 것도 아니다.

## 정원 복원

각 챕터 S02, S04, S07, S10의 최초 완료는 복원 지점을 연다. 이번 범위는 C01 4곳, C02 2곳, C04 4곳으로 총 10곳이다. 반복 완료는 새 복원 지점을 지급하지 않는다. 모든 최초 완료는 작은 꽃길 변화를 추가한다.

기존 평원 배경 위에 꽃길, 분수, 벤치, 아치의 간단한 합성 레이어를 표시한다. 복원 순서가 달라도 같은 node ID의 구조물은 같은 위치를 유지한다. 들꽃 화단, 작은 돌길, 향기로운 허브를 무료 선택하고 다시 변경할 수 있다. node별 선택은 저장되지만 현재 장면은 공통 화단과 구조물 레이어를 재사용한다. 10개의 고유 장면이나 완성된 지역 아트를 제작한 것은 아니다.

기존 CHAR_D와 CHAR_J를 유지한다. 26명 전체의 진행 해금, R1 캐릭터 4명 분량의 완성된 대사 및 고유 이야기는 후속 범위다. 정원 선택과 이야기 열람은 학습 숙련 판정이나 복습 도래 조건을 변경하지 않는다.

## 저장과 에셋

이중 슬롯 `SaveEnvelopeV1`에 날짜별 복습 행동과 stage별 마지막 플레이 날짜를 추가했다. 기존 v1 저장에 필드가 없어도 기본값으로 읽는다. 잘못된 날짜, 손상 저장과 알 수 없는 미래 schema는 진행을 임의 초기화하지 않는다.

진행 중 session에는 `stageId`, 보드, 이동 수, 획득 토큰, 식, `reviewTicketId`와 일일 복습 여부를 포함한다. 같은 진행 중 session을 열면 저장 당시 복습 여부를 우선한다. 다른 문제로 바꾸는 경우 진행 중 퍼즐 교체를 확인하며 기존 완료와 정원은 보존한다.

Android에서는 첫 전체 APK의 기존 이미지 4개를 독립 미디어 팩 `r1-media-v1`으로 앱 전용 파일에 보존한다. 이후 같은 application ID와 서명으로 이미지 없는 로직 APK를 업데이트할 수 있도록 구현했다. 원본 소스와 PNG는 삭제하지 않으며 별도 빌드 입력을 생성한다. 자세한 조건과 명령은 [에셋 분리와 앱 업데이트](ASSET_PACK_UPDATES.md)를 따른다.

- `flutter analyze --no-pub`에서 오류가 없으며 `flutter test --no-pub` 153개가 통과했다.
- `tool/verify_*.dart` 순수 Dart 검증 13개가 통과했다. 실제 R1 보드 50개의 참조 경로, 정답 AST와 정확한 session 재생을 포함한다.
- 25개 질문을 680×300에서 글자 크기 100% 및 130%로 검사했다. 네 화면 크기의 앱 흐름, 다음 날 연습, 도래 복습, 재시작 및 첫 복원을 테스트했다.

## 남은 완성 범위

콘텐츠 수로는 R1 60개 중 25개인 약 42%, 전체 420개 중 약 6%다. 저장, 화면 흐름과 일일 추천 등 공통 기반은 이미 연결되어 있으므로 이 비율은 앱 전체 완성률이 아니다.

R1에서 남은 35개는 C02 후반 5개, C03 10개, C05 10개, C06 10개다. C02 후반과 C03 앞부분을 먼저 작성해야 대응 C05 콘텐츠를 만들 수 있다. 이후 단층 봉인 이상의 보드 효과, 쉬운 보드 및 자동 섞기, R1 복원 24곳의 고유 표현, 캐릭터 및 이야기, 주간 일지와 수식 도감, 실제 기기 및 가족 관찰 검증이 필요하다. 전체 7리전 완성을 기다리기보다 R1을 먼저 베타 품질로 마무리하는 순서를 유지한다.
