# R1 60개 연속 진행 구현

R1 계산의 평원은 6챕터 60문항을 실행하고, 다음 스테이지와 일일 복습을 추천하며 정원을 복원하는 알파다. 사용자가 정의한 끊김 없는 R1 진행을 구현 범위로 삼았다. 2026-10-11 전체 Android APK 빌드·서명·미디어 포함 검증을 완료해 실기기 테스트용 공개 사전 릴리스로 제공한다. Android 설치·강제 종료·성능 검증과 가족 플레이 난도 보정은 정식 배포 전에 필요하다.

## 콘텐츠와 실행 순서

| 챕터 | 실제 문항 | 역할 | 정원 프로젝트 |
| --- | ---: | --- | --- |
| C01 | 10 | 합·차·묶음·나누기의 기본 관계 | 첫 수확의 화단 |
| C02 | 10 | 부분식과 혼합 연산 | 묶음의 과수원 |
| C03 | 10 | 괄호·순서·관계 전이 | 균형의 연못 |
| C04 | 10 | 앞 개념의 독립 의미 복습 | 기억의 씨앗길 |
| C05 | 10 | 익숙한 수학으로 2층 봉인과 직선 파워 학습 | 봉인 공방 |
| C06 | 10 | 개념 전이와 두 효과 조합 | 계산의 전망대 |

모든 문제에는 한국어 문장, 고유 토큰과 정답 AST, 관찰→관계→부분식 힌트, 오개념별 피드백, 설명된 풀이 2단계 이상, 전이 질문과 시각 자료 설명을 넣었다. 괄호는 실제 별도 토큰이며 전체 정답식은 최대 7조각이다. 숫자만 바꾸거나 fingerprint만 다르게 기록한 문제를 독립 학습 증거로 인정하지 않는다.

`regionalCampaign`의 420개 설계 원본과 기존 C01~C03 ID·skill·seed·fixture를 보존한다. `initialCampaign`에 R1 실제 60개만 덧씌우며 R2~R7의 360개는 `planned`다. 기존 개발용 체험은 별도 회귀 자료이고 캠페인 완료에 합치지 않는다.

추천 순서는 C01~C03의 미완료 코어를 먼저 진행한 뒤 미완료 C04→C05→C06으로 이어진다. C04는 해당 원본을 완료하면 조기 복습할 수 있다. C05와 C06은 앞 챕터 전체와 해당 원본 완료를 요구한다. 저장에 잠금 해제 ID만 있어도 조건 미충족이면 실행과 완료를 차단한다. C04 S10을 먼저 완료해도 남은 C04를 끝낼 때 C05가 열리므로 S10을 억지로 재도전하지 않는다. 이전 25개 완료 저장은 C02 S06부터 계속하며 이미 끝난 C04를 다시 요구하지 않는다.

## 퍼즐과 수학과 지도 연결

`월드맵 → 지역 정원 → 다음 탐험 또는 복습 → 발굴·식 조립 → 결과·해설 → 최초 완료 복원 → 지역 정원`

꿈의 정원에서 참고한 것은 퍼즐과 정원 진행의 분리다. KVM에서는 발굴 엔진, 수학 검증기, 완료 서비스가 각각 책임을 가진다. 매치만 완료하거나 정답 조각만 모두 얻어서는 캠페인 보상을 받지 않는다. 문장에 맞는 식을 완성하고 해당 보드 효과 목표를 충족한 뒤 완료 영수증으로 진도와 정원을 갱신한다.

2층 봉인은 고정된 칸에 남아 cascade당 한 층씩 감소한다. C05 S01~S02의 소개·안내 보드는 최초 이동 후 1층을 실제로 보여주고 다른 이동에서 발굴한다. 직선 파워는 4매치로 생성하고 인접 교환으로 행 또는 열을 타격한다. 다른 파워 타격에 의한 연쇄도 지원한다. C05에서 두 효과를 따로 소개하고 C06에서 조합한다. 3층·장애물·5매치 파워 등은 계속 차단한다.

60개에 동등한 5×5·6×6 보드 120개를 등록했다. 참조 경로는 합법 교환으로 탐색·재생하며 플레이어 입력을 참조 순서로 제한하지 않는다. 고급 보드 이동 예산 W/P/L은 8/10/16이며 참조 경로는 최대 6회다. 이는 최소 이동 증명이나 사람의 난도 보정 결과가 아니다. 이동 소진·데드락은 무료 검증 보드 재도전으로 연결한다. 추가 이동·자동 섞기·전용 쉬운 fixture는 아직 포함하지 않는다.

## 일일 추천과 완료 판정

도래한 학습 ticket의 독립 변형을 우선 추천하고, 없으면 이전 날짜에 완료한 문제나 열린 C04로 다음 날 연습을 제공한다. 달력 연습은 도래하지 않은 ticket을 소비하지 않으며 동일 문제를 다시 맞혔다고 독립 숙련으로 기록하지 않는다. 복습을 건너뛰어도 주 경로가 막히지 않는다.

완료 별 1개는 보장하며 수학·탐색 별은 선택 목표다. 지원받은 완료도 다음 문제와 정원을 연다. `attemptId` 완료 재전달은 기존 영수증을 반환해 별·일일 기록·복원 보상이 중복되지 않는다. 정원 장식과 이야기 열람은 학습 판정 및 복습 시점을 바꾸지 않는다.

R1 60개를 끝내면 지역 완료를 표시하고 다음 신규 탐험은 비활성화한다. 일일 복습과 자유 재도전·정원 돌보기는 유지한다. 전체 420개 캠페인 완료와 R1 완료를 구분하며, R2~R7은 과거 저장의 해금 여부와 관계없이 `업데이트 예정` 안내만 표시한다. 기존 C03 S10의 다음 리전 해금 데이터는 후속 호환성을 위해 보존한다.

## 정원과 캐릭터

각 챕터 S02·S04·S07·S10에 4곳씩 총 24개 복원 지점을 연결했다. 기존 평원 배경 위에 화단·과수원·연못·기억길·공방·전망대의 벡터 레이어를 합성한다. 첫 완료는 작은 꽃길을 늘리며 node별 장식은 들꽃·돌길·허브 중 무료로 변경할 수 있다. 돌보기 선택창은 이미 연 모든 node에 다시 접근하고 과거 체험 화단도 보존한다.

D/J는 처음부터, L은 C02 S10, U는 C03 S10에서 확정 해금한다. 기존 캐릭터 PNG를 사용하며 능력 차이와 구매는 없다. 24곳의 짧은 복원 문장과 캐릭터 4명의 이야기 열람·다시 보기를 저장한다. 여섯 장면은 공통 배경을 재사용한 합성 장면으로, 완성된 24개 고유 아트나 긴 스토리 챕터는 아니다.

## 저장과 미디어 업데이트

기존 이중 슬롯 JSON과 완료 ledger를 유지한다. 고급 세션에는 봉인 층수·파워 방향·활성 횟수와 결정론적 입력 재생을 추가했다. 기존 단층 세션의 저장 형식은 유지한다. 보드·남은 이동·획득 조각·작성 중 식·복습 ticket을 함께 복원한다.

미디어 팩은 L/U를 포함한 PNG 6개, 총 7,822,497 bytes의 `r1-media-v2`다. 앱 로직과 분리해 최초 전체 APK에서 보존하고 같은 팩을 요구하는 로직 전용 APK가 재사용한다. v1에서 v2로는 새 이미지 때문에 전체 APK 업데이트가 한 번 필요하다. 이후 같은 application ID·서명과 증가한 versionCode의 로직 전용 업데이트가 가능하도록 구현했으며 실제 설치 전환 검증은 남아 있다. [에셋 분리와 앱 업데이트](ASSET_PACK_UPDATES.md)를 따른다.

## 검증과 프리뷰

2026-10-11 최종 검증 결과는 다음과 같다.

- `flutter analyze --no-pub` 오류 0건, `flutter test --no-pub --reporter compact` 265개 통과.
- 순수 Dart `tool/verify_*.dart` 15개 통과. R1 120fixture의 합법 참조 교환 314회, 고급 최장 경로 6회를 재생했다.
- 실제 `MathAdventureApp` 테스트에서 60개 순서 완료→24곳 복원→6장면 선택→4이야기 열람→무료 장식 변경→재시작→다음 날 복습을 통과했다. 완료 데이터를 미리 채운 저장이 아니라 실제 세션·수학 제출과 완료 서비스를 사용했다.
- 같은 완료 60회 재전달이 무변경이고 저장소 12회 재생성 후 진도가 유지되는 것을 검증했다. 이전 25개 저장의 다음 C02 S06 진입과 이미 끝난 C04 건너뛰기를 확인했다.
- 강제 R2 해금 저장과 C05/C06 조기 해금 저장에서도 실행을 차단했다. 60개 질문·완성 식을 680×300 글자 100%/130%에서 검사하고 고급 상태를 네 크기에서 렌더링했다.
- 미디어 해시 검증 후 로직 전용 소스를 별도 생성했다. 생성본은 PNG 7,822,497 bytes를 제외하며 원본 소스·이미지·서명 파일을 변경하지 않는다. 실제 APK 빌드는 포함하지 않았다.
- 인앱 Chromium profile에서 기존 완료 저장을 읽고 C01 S03을 실제 클릭·발굴·식 조립으로 완료했다. 다음 S04 안내와 새로고침 후 성취 별 8개·S04 추천 유지를 확인했다. R2에는 업데이트 안내만 있고 플레이 버튼이 없었다.

## 정식 배포 전 남은 작업

1. 빌드된 전체 APK를 실제 FHD Android에 설치하고 강제 종료 복원, 60fps와 터치 사용성을 검증한다.
2. 전체 v2 APK에서 동일 서명 로직 전용 APK로 업데이트하여 미디어와 진행 유지·손상 복구를 검증한다.
3. 가족 관찰로 읽기·오답·보드 실패를 분리하고 힌트 의존·전이·지연 재인출을 측정해 난도를 조정한다.
4. 복원 아트·스토리, 추가 지원 선택, 주간 일지와 수식 도감을 보강한다.
5. R2는 실제 문항·효과·정원·저장 호환 검증을 통과한 범위만 개방한다.

전체 420개 중 60개 약 14%는 콘텐츠 수 비율이며 앱 전체 완성률이 아니다. R1 연속 플레이를 구현했다고 학습 향상이나 정식 배포 품질을 보장하지 않는다. 위 구현 단계에서는 원본 삭제와 Git 커밋·원격 push를 수행하지 않았으며, 이후 저장소 교체와 공개 APK 배포는 README 및 Release 안내를 따른다.
