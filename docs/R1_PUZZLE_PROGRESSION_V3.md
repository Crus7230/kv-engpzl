# R1 특수 블록·장애물 단계 도입

## 변경 범위와 검증 상태

2026-10-12 초기에는 소스 변경만 수행했으며, 이후 사용자 승인으로 R2 포함 Flutter 분석 이슈 0개·전체 테스트 556개 통과(배포 검증 1개 제외)·웹 프리뷰까지 확인했다. APK 빌드와 GitHub 릴리즈는 하지 않았다. 검증 세부 범위는 [R2 구현·실행 검증](R2_ALPHA_IMPLEMENTATION.md)에 기록한다.

수학 문항·정답 AST·토큰 manifest·스테이지 ID·학습 증거·완료 보상은 유지한다. 보드만 새 physics3 fixture로 구분한다. 후속 R2 확장은 별도 authored overlay로 활성화했고, R3~R7은 `planned`와 `업데이트 예정` 상태를 유지한다.

`R1BoardProgression`을 실제 R1 보드 설정의 단일 원천으로 사용한다. 기존 지역 청사진은 보존한다. `challengeLevel`은 거친 B tier와 별도로 실제 규칙·밀도 증가를 추적한다. 수학 tier와 물리 난도가 함께 오르면 validator가 거부한다. 소개 문제는 앞선 실제 문항의 source ID를 검증한다. 사람 플레이를 통한 난도 보정은 별도로 필요하다.

## 특수 블록과 장애물

- 4개 일렬 매치: 가로 또는 세로 직선 파워.
- 5개 일렬 매치: 색상 파워. 다른 모양보다 우선한다. 일반 보석과 바꾸면 해당 색을 타격한다.
- L/T 교차 매치: 주변 3×3 범위 폭발.
- 직선 + 직선: 교환 지점 중심 십자.
- 직선 + 폭발: 3행과 3열 타격.
- 폭발 + 폭발: 주변 5×5 타격.
- 색상 + 직선/폭발: 같은 색 보석을 해당 특수 효과로 변환해 연쇄 활성.
- 색상 + 색상: 전체 보드 타격.
- 인접 타격 장애물: 교환·매치·낙하를 막는 고정 덮개. 인접 매치 또는 직접 특수 타격으로 한 연쇄당 한 층 제거.

범위는 보드 밖으로 나가지 않으며, 겹친 효과도 봉인·장애물을 연쇄당 한 번만 타격한다. 일반 색상 교환은 두 특수 블록의 조합 목표로 세지 않는다. 조합은 소개 이후에만 활성화한다. 직선형·범위형·색상형 아이콘, 접근성 설명과 각 타격 범위의 모션을 구분한다.

소개 스테이지에서 해당 효과의 활성화까지 요구한다. 연습 스테이지의 특수 블록은 선택 도구이며 매번 강제 활성화하지 않는다. 장애물이 있는 보드는 장애물 제거도 완료 목표로 포함한다. 도움 사용에 따른 진행·보상 정책은 변경하지 않는다.

## 저장 호환성과 해금

새 체크포인트는 `sessionVersion: 1`, `rulesVersion: 3`으로 기록한다. 보드, 이동, 조각·식뿐 아니라 효과별 활성 수, 조합 수, 제거된 장애물을 결정적 재생으로 확인한다.

`rulesVersion`이 없는 저장본은 v1 보드·이동 예산·직선 파워 규칙으로 복원한다. 현재 캠페인 완료 기록과 보상 원장은 초기화하지 않는다. 이미 완료한 스테이지 재도전과 진행 중인 v1 세션은 새 복습 해금 조건 때문에 차단하지 않는다. 알 수 없는 규칙 버전은 거부하며 저장소를 자동 덮어쓰지 않는다. 앱의 기존 복원 실패 대화상자는 사용자가 현재 퍼즐만 재시작할지 선택하도록 유지한다.

매일 추천, 지도 입장, 완료 처리에서 같은 `CampaignAccessPolicy`를 사용한다. C04의 source-linked 조기 해금 ID가 저장되어 있어도 특수 블록 수업 선수 조건은 별도로 확인한다. R2 이후 기존 파워 슬롯은 세 파워·조합을 재사용하도록 연결하지만, 미구현 포털·컨베이어·교환 잠금·별도 고정 장애물은 여전히 차단한다.
