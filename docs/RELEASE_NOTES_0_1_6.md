## 다운로드와 설치

[Android APK 다운로드](https://github.com/Crus7230/kv-engpzl/releases/download/v0.1.6-r1-alpha/KVM-R1-0.1.6-alpha.apk)

버전은 `0.1.6+7`, 패키지는 `com.crus7230.kvm.renewal`이며 Android 7.0 이상과 가로 화면을 지원합니다. R1·R2의 120개 스테이지를 포함하며 R3~R7은 업데이트 예정입니다. 파일명의 R1 표기는 기존 업데이트 인식 계약을 유지하기 위한 것입니다.

이번 APK에는 배경·캐릭터 이미지와 음악·효과음 파일이 없습니다. 먼저 공개한 [이미지 팩 r1-media-v3](https://github.com/Crus7230/kv-engpzl/releases/tag/media-r1-v3) 약 15.2MB를 최초 실행에서 한 번 다운로드합니다. 이미 검증된 팩이 있으면 다시 받지 않습니다. [음원 팩 audio-v1](https://github.com/Crus7230/kv-engpzl/releases/tag/media-audio-v1) 약 17.1MB는 선택 다운로드이며 나중에 설정에서도 받을 수 있습니다. ZIP을 수동 설치할 필요는 없습니다. 팩 설치 후 기본 플레이는 오프라인으로 가능합니다.

v0.1.5와 동일한 개발용 인증서로 서명한 release APK입니다. 기존 앱을 삭제하거나 데이터를 지우지 말고 APK로 업데이트하세요. 저장 epoch `expedition-1`, 별·완료·구출·이야기·복습과 중단 퍼즐을 유지합니다. 신규 설치는 캐릭터 선택과 필수 튜토리얼부터 시작합니다. 앱 삭제·데이터 지우기·새 기기에서는 팩을 다시 받습니다. Google Play 정식 배포본은 아닙니다.

## 변경 사항

- 시작 인트로와 탐험·퍼즐 BGM을 루프로 재생합니다. 사용자 제공 MP3 4곡 중 인트로와 게임 곡을 각각 선택할 수 있습니다.
- 보석·풀이 블록 선택, 교환, 제거와 특수 효과에 자체 제작 효과음을 연결했습니다.
- 선택·교환·매치·풀이 블록 획득·정답에 햅틱을 연결했습니다. 음악·효과음·햅틱을 개별 ON/OFF하고 음악·효과음 음량을 저장합니다.
- 다른 앱·홈 화면으로 이동하거나 audio focus를 잃으면 음악·효과음을 멈춥니다. 복귀 시 이어 재생하며 현재 곡을 화면 갱신마다 다시 시작하지 않습니다.
- 동료 도감의 `이 동료로 탐험하기`로 구출한 동료 또는 처음 고른 캐릭터를 내 모험 캐릭터로 선택합니다. 동료 편성 변경이 아니며 미구출 캐릭터는 선택할 수 없습니다. 최초 캐릭터와 합류 이야기 기록을 별도로 유지합니다.
- R1·R2 C04에서 얼음 속 풀이 블록, 일정 이동 후 내려오는 블록과 색상 제거 보상을 도입합니다. C05~C06에서는 파란색 12/20개, 초록색 12개 등의 목표를 조합합니다. 복합 목표는 모두 만족해야 완료됩니다.
- 밀도 높은 보드는 넓은 800×360 이상 화면에서 7×7, 작은 화면에서 6×6으로 배치합니다. 새 수학과 새 보드 난도를 동시에 올리지 않는 단계 구성을 유지합니다.
- 새 시도는 퍼즐 규칙 v4를 사용하고 저장된 v1/v3 시도는 원래 규칙으로 이어갑니다. 튜토리얼·R1 통합 테스트도 현재 세션의 실제 검증 경로를 사용하도록 수정했습니다.
- 두 다운로드 팩은 ZIP 및 개별 파일의 크기·SHA256을 확인한 뒤 앱 전용 저장소에 설치합니다. 앱 업데이트에서 같은 팩을 재사용하며 진행 저장과 분리합니다.
