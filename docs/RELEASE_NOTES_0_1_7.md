버전은 `0.1.7+8`, 패키지는 `com.crus7230.kvm.renewal`이며 Android 7.0 이상과 가로 화면을 지원합니다. R1·R2 각 60개, 총 120개 스테이지를 포함하며 R3~R7은 업데이트 예정입니다. 파일명의 R1 표기는 기존 앱 업데이트 인식 계약을 유지한 것입니다.

## 변경 사항

- 신규 일반 스테이지에 18~20회 이동을 제공합니다. `필수 풀이 블록 획득 + 색상·특수 과제 달성 + 올바른 수식`을 모두 만족해야 완료됩니다. 튜토리얼은 짧은 안내 보드를 유지합니다.
- 보석·풀이 블록·장애물을 먼저 독립적으로 랜덤 배치하고, 같은 보충 seed로 완료 경로를 확인한 후보를 사용합니다. 검증 경로에 맞춰 블록을 옮기거나 보충 순서를 바꾸지 않습니다. 검증은 제한된 휴리스틱 검사이며 모든 선택의 성공을 보장하지 않습니다.
- 무료 재도전은 새 랜덤 seed와 시도 ID를 사용합니다. 중단 복원은 저장된 seed와 보드·작성 중인 식을 그대로 이어갑니다. 좋은 연쇄로 빨리 완료하는 것을 막는 최소 턴 잠금은 없습니다.
- 같은 보드 영역에 일반 6×6(36칸), C04 S02 이후 고밀도 대상은 사용 가능 영역 720×320dp 이상에서 7×7(49칸)을 배치합니다. 튜토리얼과 매우 작은 화면은 5×5이며, 680×300에서는 6×6을 사용합니다. 크기는 SafeArea 후 논리 화면 기준입니다.
- 질문·목표·정답식 공간은 유지하고 보석과 간격을 줄였습니다. 480×270에서 글자 130%로 확대할 때 넘치던 상단 난이도 표시도 수정했습니다. 긴 난이도 문구는 길게 눌러 전체 내용을 볼 수 있습니다.
- 힌트 버튼을 다시 누르면 닫힙니다. 마지막 수학 힌트도 닫았다가 다시 열 수 있고, 힌트 사용 기록은 유지합니다. 남은 색상 목표 안내와 풀이 블록 발굴 안내를 구분했습니다.
- 기존 v1·v3·v4 세션과 진행 중 보드 크기는 소급 변경하지 않습니다. 확대 보드와 새 목표는 새 스테이지 세션부터 적용됩니다. 같은 기존 세션의 재도전은 기존 크기를 유지합니다.
- 기존 BGM·효과음·햅틱·모험 캐릭터 변경·R2 탐험과 보석 모션은 유지합니다. 추가 음원이나 런타임 의존성은 없습니다.
