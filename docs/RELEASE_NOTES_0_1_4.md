# KV 수학탐험대 2026 v0.1.4 — 탐험 시작 버전

<!-- kvm-update: {"schema":1,"versionName":"0.1.4","versionCode":5} -->

R1 계산의 평원 탐험과 필수 튜토리얼을 새 시작 기준으로 묶은 공개 알파입니다. R1 60개 스테이지를 플레이할 수 있으며 R2~R7은 `업데이트 예정`입니다.

## 변경 사항

- 최초 한 번 26명 중 내 캐릭터를 선택하고 실제 첫 발굴·수식 문제를 완료한 뒤 모험을 출발합니다. 중단하면 해당 단계부터 이어집니다.
- R1을 6개 탐험 목적지와 챕터별 스테이지 경로로 구성하고, 기존 복원 24곳을 길·거점·이정표를 여는 탐험 진행으로 연결했습니다.
- C01 S10에서 D/J, C03 S10에서 L, C05 S10에서 U가 합류합니다. 선택한 캐릭터는 중복 구출하지 않습니다.
- 동료 탭에서 확보한 캐릭터의 정보를 확인합니다. 기존 앱의 26명 프로필·이미지를 승계했습니다.
- R1 배경과 D/J 아트를 개선했습니다. 기존 매치 퍼즐 모션, 복습 추천, 해설과 중단된 보드·식 복원, 중복 보상 방지를 유지합니다.

## 설치와 진행 초기화

이번 버전을 새 시작점으로 삼는 승인된 초기화 정책을 적용했습니다. v0.1.3 이하 Renewal의 진행은 이어 읽지 않고 캐릭터 선택과 튜토리얼부터 시작합니다. 기존 저장 원본과 미디어는 물리적으로 삭제하지 않습니다. 이번 버전부터 만든 진행은 이후 일반 업데이트에서 유지하도록 같은 저장 epoch를 사용합니다.

전체 미디어 포함 `KVM-R1-0.1.4-alpha.apk` 하나를 제공합니다. 신규 설치와 이전 미디어 팩 v1/v2에서 이번 v3로 올라오는 업데이트 모두 이 파일을 사용합니다. 앱 삭제·데이터 지우기는 필요하지 않습니다. v0.1.3은 시작 시 새 버전을 안내할 수 있으며, 설치는 Android 설치 화면에서 직접 확인해야 합니다. 인터넷이 없거나 조회가 실패해도 기본 플레이는 가능합니다.

패키지는 `com.crus7230.kvm.renewal`, 버전은 `0.1.4`, versionCode는 `5`입니다. Android 7.0 이상과 가로 화면을 지원합니다. 이전 Renewal과 같은 개발용 키로 서명한 release 모드 APK이며 Google Play 정식 배포본이 아닙니다.
