# KV 수학탐험대 2026 v0.1.5 — R2 탐험과 확대된 지도

<!-- kvm-update: {"schema":1,"versionName":"0.1.5","versionCode":6} -->

## 변경 사항

- R2 규칙과 패턴의 숲 60개를 추가했습니다. R1 60개와 함께 총 120개 실제 스테이지를 플레이할 수 있습니다.
- R1 C03 S10 완료 후 R2가 열립니다. R1 C04~C06은 남겨 두고 숲 탐험을 시작할 수 있습니다. R3~R7은 업데이트 예정입니다.
- 규칙·수열·표·묶음 관계·괄호와 지역 간 전이 문제에 단계별 힌트, 오개념 피드백, 풀이 해설과 복습을 연결했습니다.
- R1 초반부터 4매치 직선 파워, 방해 요소, L/T 파워, 5매치 파워를 배우고 후반과 R2에서 2층 봉인·덩굴·특수 조합으로 확장합니다. 새 수학과 새 보드 난도를 동시에 올리지 않는 구성입니다.
- R2의 6개 탐험 목적지와 흔적 24곳, B·F·R·N 동료 합류를 연결했습니다. R1·R2 전체 흔적은 48곳입니다.
- 월드맵 하단 큰 카드 3개를 48px 높이의 플로팅 버튼으로 바꿨습니다. 800×360 기준 지도 그림은 약 574×231에서 756×304로 커졌습니다.
- 기억의 씨앗은 복습, 오늘의 탐험은 다음 문제 또는 저장된 시도, 탐험의 흔적은 이정표·쉼터 변경을 담당합니다. 상세 안내는 길게 누르면 확인할 수 있습니다.
- 저높이 화면과 글자 확대 배치를 보완했습니다. 검증용 빨간 리본과 미리 채운 진행 기록은 일반 앱에 포함하지 않습니다.
