## 변경 사항

- 별도 모험 인트로에서 기존 앱의 순차 페이드인 느낌을 승계했습니다. 로고·제목·설명·준비 상태가 차례로 나타나며, 실제 준비 완료와 함께 모험으로 진입합니다.
- 음악 설정을 하나로 통일했습니다. 기본 선택에서는 인트로 곡과 게임 BGM을 구분하고, 사용자가 곡을 선택하면 인트로에서도 같은 곡을 사용합니다. 앱이 배경으로 이동하면 음악을 중단합니다.
- 큰 가로·폴더블 화면은 최대 960×432 논리 픽셀의 게임 영역을 중앙에 유지합니다. 정사각형에 가까운 창은 20:9 비율로 여백을 두며, 저높이 일반 가로 폰의 가용 높이는 보존합니다.
- 기억의 씨앗은 개념별 새싹·꽃봉오리·기억꽃과 날짜별 복습 꽃잎을 모읍니다. 씨앗 성장 삽화·꽃잎 가랜드·선택 모션을 추가했습니다. 꽃의 수집 기록과 학습 숙련도는 분리합니다.
- 탐험의 흔적은 챕터 도장·이정표·최근 7일 발걸음·모험 배지가 있는 탐험 여권으로 표시합니다. 챕터 미니 지도, 진행 경로, 도장 등장 모션, 리본형 배지를 추가했습니다.
- 수집 삽화는 코드로 그리며 추가 이미지 팩이나 런타임 라이브러리가 필요하지 않습니다. 짧은 등장·선택 모션은 재생 후 멈추고 모션 감소 설정에서는 정지 화면을 사용합니다.
- 지도의 열린 툴팁이 메뉴 이동·폴더블 크기 변경 뒤 이전 크기를 사용하는 문제를 보완했습니다.
