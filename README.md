# KV 수학탐험대 — R1·R2 알파

매치 퍼즐에서 숫자와 기호를 발굴하고, 문장에 맞는 수식을 완성해 탐험의 길을 여는 Android 게임입니다. 기존 KVM을 Flutter/Dart로 재구성했습니다. 계산의 평원(R1)과 규칙과 패턴의 숲(R2) 각 60개, 총 120개를 플레이할 수 있습니다. R1 C03 S10을 완료하면 R2가 열리고 R3~R7은 `업데이트 예정`입니다.

## 다운로드와 설치

[Android APK 다운로드 — v0.1.10 저높이 보드·2×2 유도탄](https://github.com/Crus7230/kv-engpzl/releases/download/v0.1.10-r1-alpha/KVM-R1-0.1.10-alpha.apk)

[릴리스 안내와 파일 정보](https://github.com/Crus7230/kv-engpzl/releases/tag/v0.1.10-r1-alpha)

1. Android 휴대폰에서 위 APK를 다운로드합니다. GitHub의 `Code → Download ZIP`은 소스이며 설치 파일이 아닙니다.
2. 다운로드한 APK를 열고, 필요한 경우 다운로드에 사용한 브라우저 또는 파일 앱에만 출처가 다른 앱 설치를 허용합니다.
3. 설치 후 `KV 수학탐험대 2026`을 실행합니다. 최초 설치는 이미지 팩 약 15.2MB를 한 번 다운로드합니다. 새 음원 팩 audio-v2 약 29.9MB는 선택 사항이며 기존 audio-v1 사용자도 설정에서 새 팩을 받을 수 있습니다. ZIP을 직접 압축 해제할 필요는 없습니다.
4. 가로 화면에서 내 캐릭터를 고르고 첫 발굴·수식 튜토리얼을 완료한 뒤 R1 탐험을 출발합니다. 기존 설치는 앱 삭제나 데이터 지우기 없이 APK로 업데이트합니다.
5. 설치가 끝나면 해당 앱의 출처가 다른 앱 설치 허용을 다시 끌 수 있습니다. 기기의 보안 검사 전체를 끄지 마세요.

| 항목 | 이번 배포 |
| --- | --- |
| 지원 OS | Android 7.0 이상 (`minSdk 24`) |
| 화면 | 스마트폰 가로 모드, FHD/20:9 저높이 화면 대응 |
| 버전 | `0.1.10`, versionCode `11` |
| 패키지 | `com.crus7230.kvm.renewal` |
| 설치 파일 | 이미지·음원 미포함 다운로드형 APK. 크기·해시는 릴리즈 안내 참조 |
| 서명 | 개발용 Android Debug 키, release 모드 빌드 |

v0.1.1부터 Renewal은 기존 KVM과 v0.1.0의 `com.user.kvm`과 별도 앱으로 설치됩니다. v0.1.10은 이전 Renewal과 패키지·인증서가 같고 versionCode가 증가한 업데이트입니다. 앱 삭제·데이터 지우기는 필요하지 않습니다. 실제 휴대폰 업데이트 검증은 남아 있습니다.

v0.1.10은 저장 epoch `expedition-1`과 이미지 `r1-media-v3`·음원 `audio-v2`를 유지하며 새로운 초기화나 팩을 요구하지 않습니다. v0.1.4 이상 진행을 이어 쓰고 이미 받은 팩은 재사용합니다. 이전 audio-v1 사용자만 설정에서 audio-v2 약 30MB를 한 번 받으면 됩니다. 신규 설치는 캐릭터 선택과 필수 튜토리얼부터 시작합니다. v0.1.3 이하에서는 v0.1.4의 새 시작 정책이 적용되며 이전 저장 원본·미디어를 물리적으로 삭제하지 않습니다. 진행 중 퍼즐은 기존 크기·규칙으로 복원하고 새 일반 세션만 v6 유도탄 규칙을 사용합니다.

v0.1.3 이상은 시작 로딩 중 이번 업데이트를 안내할 수 있습니다. v0.1.2 이하에는 앱 내 업데이트가 없어 위 APK를 직접 설치합니다. 신규 설치·이전 버전 업데이트 모두 이번 다운로드형 APK를 사용합니다. 파일명의 R1 표기는 기존 앱의 업데이트 인식 규칙을 유지하기 위한 것이며 실제 내용은 R1·R2를 포함합니다.

이 배포는 실기기 테스트를 위한 공개 **알파 사전 릴리스**입니다. 개발용 서명으로 직접 설치할 수 있지만 정식 배포용 키나 Google Play 배포본이 아닙니다. 이후 같은 `com.crus7230.kvm.renewal` 앱을 업데이트할 때에는 같은 서명과 증가한 versionCode가 필요합니다. 설치 오류가 나면 보안 검사 전체를 끄거나 앱 데이터를 삭제하지 말고 오류 문구를 [Issues](https://github.com/Crus7230/kv-engpzl/issues)에 알려주세요.

APK의 크기·SHA256과 검증 결과는 [v0.1.10 릴리즈 기록](docs/RELEASE_NOTES_0_1_10.md)을 확인하세요.

이번 소스는 분석 이슈 0개, 전체 테스트 693개와 게시 후 공개 업데이트 인식 검사 1개를 통과했습니다. APK v2 서명·기존 인증서·빌드 입력 223개 일치·미디어 미포함을 확인했습니다. APK는 51,014,155 bytes(약 48.7MiB)이며 로그인 없는 실제 다운로드의 크기·SHA256이 원본과 같습니다. 이전 릴리즈 13개와 파일을 보존했습니다. 실제 휴대폰의 설치·다운로드·청취·햅틱·터치감은 추가 확인이 필요합니다.

## v0.1.10 변경 사항

- 저높이 문장·제목 크기를 줄이고 보드를 우선 확보합니다. 목표는 보드 위 여러 줄 글씨 대신 상단 아이콘·수량·진행 막대로 표시하고 눌러 설명을 확인합니다.
- 568×256·640×280·680×300의 5×5/6×6/7×7 보드와 글자 100%/130%를 확인했습니다. 긴 문제는 스크롤·크게 읽기로 이어 보며 저장된 보드를 자르지 않습니다.
- 음악은 목록에서 누르면 즉시 변경·자동 저장합니다. 별도 저장은 접근성 설정에만 필요합니다.
- 같은 색 2×2 매치로 유도탄을 만들고 인접 교환으로 목표 한 칸을 타격합니다. 유도탄끼리 및 다른 특수 블록과의 조합도 지원합니다.
- 기존 진행·R1/R2 120개·미디어 팩을 유지합니다. APK에는 이미지·음원을 추가하지 않았으며 새 런타임 의존성이 없습니다.

## 추가 음원 팩 audio-v2

새 `Glass Horizon`, `Highest Point of the Swing`, `Painted Ponies Turning`을 포함해 음악 7곡·효과음 4개, 약 29.9MB의 [audio-v2](https://github.com/Crus7230/kv-engpzl/releases/tag/media-audio-v2)를 별도 팩으로 공개했습니다. 원본·audio-v1·진행 기록은 유지합니다. **위 APK 0.1.9부터 설정에서 audio-v2를 받아 새 곡을 선택할 수 있습니다.** APK 0.1.8까지는 audio-v1을 사용하므로 먼저 앱을 업데이트해야 합니다. 같은 팩을 쓰는 다음 코드 업데이트에서는 음원을 재다운로드하지 않습니다. [음원 기록](docs/AUDIO_PACK_V2.md)과 [앱 업데이트 안내](docs/RELEASE_NOTES_0_1_9.md)를 참고하세요.

## v0.1.9 변경 사항

- 음악 목록에 새 BGM 3곡을 추가해 인트로곡 포함 7곡을 선택합니다. 직접 선택한 곡은 인트로와 탐험에서 이어 재생합니다.
- 설정에서 audio-v2를 명시적으로 다운로드·검증합니다. 음악·효과음 파일은 APK에 넣지 않습니다. 새 팩은 약 30MB이며 팩당 한 번 받습니다.
- 기존 패키지·서명·진행·이미지 팩·루프·백그라운드 정지·효과음·햅틱을 유지합니다. 음악 다운로드나 변경은 학습·퍼즐 기록을 초기화하지 않습니다.

## v0.1.8 변경 사항

- 기존 앱의 순차 페이드인 느낌을 승계한 별도 모험 인트로를 추가했습니다. 음악 선택은 하나로 통일해 사용자가 선택한 곡을 인트로에서도 사용합니다.
- 큰 가로·폴더블 화면은 최대 960×432 논리 픽셀의 중앙 가로 영역으로 유지합니다. 정사각형에 가까운 창은 20:9 비율을 유지하며 일반 저높이 가로 폰의 가용 높이는 보존합니다.
- 기억의 씨앗은 개념별 새싹·꽃봉오리·기억꽃, 날짜별 복습 꽃잎·다발과 삽화·선택 모션으로 구성했습니다. 꽃 수집과 학습 숙련도는 분리합니다.
- 탐험의 흔적은 챕터 미니 지도·도장·최근 7일 발걸음·이정표·리본형 배지가 있는 탐험 여권입니다. 발견한 흔적과 합류 이야기를 다시 볼 수 있습니다.
- 모션은 짧게 재생한 뒤 멈추며 모션 감소 설정에서는 정지 화면입니다. 코드로 그리는 삽화이므로 이미지·음원 팩이나 런타임 라이브러리를 추가하지 않습니다.
- 지도 툴팁의 메뉴 이동·크기 변경 문제를 보완했습니다. 기존 진행·R1/R2·랜덤 발굴·효과음·햅틱·모험 캐릭터 변경은 유지합니다.

## v0.1.7 변경 사항

- 튜토리얼 이후 신규 일반 시도에 18~20회 이동을 제공하며, 풀이 블록 획득·색상/특수 과제·정답 수식을 모두 만족해야 완료됩니다.
- 먼저 독립 랜덤 배치한 뒤 같은 보충 seed로 완료 경로를 검사합니다. 정답 경로에 블록을 심지 않습니다. 무료 재도전은 새 seed, 중단 복원은 같은 seed를 사용합니다.
- 일반 보드는 6×6, C04 S02 이후 고밀도 대상은 SafeArea 후 720×320dp 이상에서 7×7입니다. 튜토리얼·매우 작은 화면은 5×5입니다. 질문·목표·정답식 공간을 유지하고 보석 크기와 간격을 줄였습니다.
- 힌트 버튼으로 표시를 닫을 수 있으며 마지막 수학 힌트도 다시 열 수 있습니다. 힌트 사용 기록은 유지합니다.
- 480×270·글자 130%에서 넘치던 상단 난이도 표시를 수정했습니다. 긴 문구는 길게 눌러 전체 내용을 볼 수 있습니다.
- 진행 중인 기존 보드·이야기·구출·복습·모험 캐릭터와 설치된 미디어 팩을 유지합니다. 새 런타임 의존성이나 음원을 추가하지 않습니다.

## v0.1.6 변경 사항

- 인트로·탐험 BGM 루프, 퍼즐 선택·교환·제거·특수 효과음을 추가했습니다. 홈/다른 앱 전환과 audio focus 손실 시 멈추고 복귀하면 이어 재생합니다.
- 설정에서 음악·효과음·햅틱을 개별 조절하고 음악·효과음 음량과 인트로/게임 곡을 선택합니다. 햅틱은 음원 다운로드와 독립적입니다.
- 동료 도감에서 구출한 동료 또는 최초 선택 캐릭터를 내 모험 캐릭터로 변경합니다. 동료 편성 변경이 아닙니다. 진행·구출·이야기는 유지됩니다.
- R1·R2 후반에 얼음 속 풀이 블록, 조건 달성 후 내려오는 블록, 파란색/초록색 제거 복합 목표를 연결했습니다. 넓은 저높이 화면은 7×7, 작은 화면은 6×6으로 보드 복잡도를 늘립니다.
- 이미지·음원 ZIP을 먼저 별도 릴리즈로 공개하고 APK에서는 두 manifest만 포함합니다. 다운로드는 최초 동의 시만 진행하고 다음 코드 업데이트에서 재사용합니다.

[이미지 팩](https://github.com/Crus7230/kv-engpzl/releases/tag/media-r1-v3), [음원 팩](https://github.com/Crus7230/kv-engpzl/releases/tag/media-audio-v1)은 앱이 자동 검증·설치하며 APK 업데이트 후보에서는 제외합니다.

## v0.1.5 변경 사항

- R2 규칙과 패턴의 숲 60개와 6개 탐험 목적지·흔적 24곳을 추가했습니다. B·F는 C01 S10, R은 C03 S10, N은 C05 S10 이후 합류합니다.
- R1 C03 S10 완료 후 R2로 이어집니다. 지역 지도에서는 선택한 지역의 다음 문제를, 월드맵에서는 전체 캠페인의 다음 본 경로를 추천합니다.
- 월드맵의 큰 카드 3개를 48px 플로팅 버튼으로 변경했습니다. 800×360 기준 지도 그림은 약 574×231에서 756×304로 확대됐습니다. 상세 안내는 길게 누르면 확인할 수 있습니다.
- 4매치 직선 파워·L/T 파워·5매치 파워, 2층 봉인·덩굴·특수 조합을 단계별로 배웁니다. 새 수학과 새 보드 난도를 동시에 올리지 않는 구성입니다.
- 문장에서 연산 관계와 부분식을 찾아 조립하는 학습 지원, 저높이 질문 배치와 글자 확대를 보완했습니다.
- 일반 앱은 정상 진입점으로 빌드해 R2 검증용 리본·미리 채운 완료 기록을 제외했습니다. 기존 진행을 유지합니다.

아래 탐험 시작 기능도 계속 제공합니다.

- 최초 한 번 26명 중 플레이어 캐릭터를 선택하고 실제 C01 S01 튜토리얼을 완료해야 모험을 출발합니다. 종료 후에는 선택·보드·식 또는 출발 단계부터 이어집니다.
- R1의 6개 탐험 목적지와 챕터별 경로, 안개·해금·다음 추천·선택 캐릭터 표시를 연결했습니다. 기존 복원 24곳은 길·거점·이정표를 여는 탐험 진행으로 전환했습니다.
- C01 S10에서 D/J, C03 S10에서 L, C05 S10에서 U가 합류합니다. 플레이어로 고른 동료는 중복 구출하지 않습니다.
- 동료 탭은 기존 앱의 26명 프로필·이미지를 승계하고 확보한 동료 정보를 보여줍니다. R1 지도 배경과 D/J 아트를 개선했습니다.
- 기존 아이콘·시작 화면과 보석 교환→제거→낙하·보충→연쇄 모션, 스와이프와 모션 감소 설정을 유지합니다.
- 앱 시작 시 GitHub의 공개 릴리스 목록을 최대 5초 확인합니다. 오프라인·시간 초과·조회 실패 시 기존 게임을 계속 사용할 수 있습니다.
- 새 APK가 있으면 다운로드 또는 나중에 계속하기를 선택합니다. 크기·SHA256·패키지·버전·현재 설치 앱과 같은 인증서를 확인한 뒤 Android 설치 화면을 엽니다. 업데이트 모듈 자체는 진행·미디어를 변경하지 않으며, 이번 초기화는 별도로 승인된 앱 저장 epoch 변경입니다.
- Android가 설치 허용을 요구하면 앱의 `설치 허용 설정`을 열고, 허용 후 돌아와 `설치 다시 열기`를 누릅니다. 무인 설치나 강제 업데이트가 아니며 취소할 수 있습니다.

자동 업데이트는 이 공개 APK 배포용입니다. 향후 Google Play 배포는 해당 정책과 업데이트 방식에 맞게 별도 검토해야 합니다.

## 플레이 흐름

`캐릭터 선택 → 필수 첫 문제 → 출발 → 월드맵·R1/R2 탐험 지도 → 복습 또는 다음 스테이지 → 매치·발굴 → 수식 완성·해설 → 탐험 이정표·동료 합류 → 다음 추천`

- R1과 R2는 각각 6챕터 × 10개 스테이지입니다. 기본·혼합 연산·괄호, 규칙·수열·표, 복습과 보드 효과 학습, 전이 문제로 이어집니다.
- 수학 풀이와 매치 퍼즐과 지도 진행은 별도 모델로 연결합니다. 매치만 하거나 숫자만 모아서는 완료되지 않습니다.
- 3단계 힌트, 오개념 피드백과 풀이 해설을 제공합니다. 힌트를 사용해도 다음 스테이지와 복원 보상은 막지 않습니다.
- 도래한 복습과 다음 탐험을 추천합니다. 빠진 날짜를 벌주거나 연속 출석을 초기화하지 않습니다.
- 탐험 이정표는 R1·R2 합계 48곳입니다. 챕터 진행으로 동료를 확보하고, 확보한 동료의 프로필·합류 이야기를 다시 볼 수 있습니다.
- 중단한 보드와 작성 중인 식, 진행과 복원을 저장합니다. 첫 완료 보상은 중복 지급하지 않습니다.
- 광고, 결제, 가챠, 생명과 대기시간은 없습니다. 인터넷 연결 없이 기본 플레이를 할 수 있습니다.

진행 구조는 꿈의 정원(Gardenscapes)의 퍼즐·정원 분리를 장르 참고점으로 삼았습니다. 기존 KVM의 세계관·캐릭터와 인접 교환 퍼즐을 유지합니다.

## 검증 범위와 알려진 제한

최신 분석·전체 Flutter 테스트·APK 서명과 공개 다운로드 검증 범위는 [v0.1.10 릴리즈 기록](docs/RELEASE_NOTES_0_1_10.md)을 기준으로 합니다. 이전 검증 결과는 해당 버전 문서에 보존했습니다. 자동 검증은 실제 청취·진동·기기 설치·사람 플레이를 대체하지 않습니다.

실제 Android 휴대폰의 설치·앱 내 APK 다운로드·설치 확인·강제 종료 복원·성능과 전체 APK에서 로직 전용 APK로의 업데이트는 아직 검증하지 않았습니다. 웹·Flutter viewport 캡처는 실제 기기 검증이 아닙니다. 아트·스토리 확장과 사람 플레이에 따른 난도 보정은 계속 개발합니다. 학습 성취 향상은 실제 사용자 연구로 확인한 결과가 아닙니다.

오류를 제보할 때는 기종, Android 버전, 앱 버전, 스테이지 ID, 재현 순서와 화면을 알려주세요. 개인정보나 기기 식별자를 포함할 필요는 없습니다.

## 에셋과 향후 업데이트

이번 공개 APK에는 이미지·음원이 없습니다. 최초 설치는 이미지 팩 `r1-media-v3`를 내려받고 음원 팩 `audio-v1`은 선택적으로 받습니다. 앱 전용 저장소에 검증·보존한 팩은 같은 팩을 사용하는 다음 APK 업데이트에서 재사용합니다. 로직 수정도 APK 업데이트이며 원격 Dart 코드 패치가 아닙니다.

업데이트에는 같은 application ID·서명, 증가한 versionCode가 필요합니다. 앱 삭제·데이터 초기화·새 기기에서는 팩을 다시 다운로드합니다. 최초 이미지 다운로드 전에는 인터넷이 필요하고 팩 준비 후 기본 플레이는 오프라인으로 가능합니다. 기본 pubspec은 개발·Web·전체 오프라인 빌드용이며 공개 APK는 `tool/prepare_logic_only_source.ps1`로 생성한 별도 입력에서 빌드합니다. 정식 키로 전환할 때의 설치·진행 이전 정책은 별도로 확정해야 합니다.

[R2 구현과 검증 상세](docs/R2_ALPHA_IMPLEMENTATION.md), [v0.1.5 릴리즈 안내](docs/RELEASE_NOTES_0_1_5.md), [R1 구현과 검증 상세](docs/R1_COMPLETE_ALPHA_IMPLEMENTATION.md), [에셋 분리와 업데이트](docs/ASSET_PACK_UPDATES.md), [학습·복습 설계](docs/LEARNING_PROGRESSION_DESIGN.md)를 참고하세요. 이전 단계의 문서는 당시 구현과 검증 기록이며 이번 APK 배포 상태는 이 README와 해당 Release 안내를 기준으로 합니다.

### 이후 APK 게시 계약

업데이트 조회는 알파도 포함하는 공개 `/releases?per_page=20` 목록을 사용합니다. 초안과 미디어 팩·잘못된 메타데이터는 무시합니다. 현재 채널은 `vX.Y.Z-r1-alpha` 또는 `vX.Y.Z` 태그와 `KVM-R1-X.Y.Z-alpha.apk` 설치 가능한 APK를 사용합니다. 릴리스 본문에 다음 형식의 한 줄을 넣고 실제 APK와 versionCode를 일치시켜야 합니다.

```html
<!-- kvm-update: {"schema":1,"versionName":"0.1.7","versionCode":8} -->
```

다음 버전에서는 값과 파일명을 함께 변경하고 versionCode를 반드시 증가시킵니다. APK 하나를 첨부하고 GitHub asset의 크기·SHA256 digest, 공개 다운로드와 설치 서명을 검증한 뒤 공개합니다. 현재 앱 버전과 같거나 오래된 버전은 안내하지 않습니다.
