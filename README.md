# KV 수학탐험대 — R1 알파

매치 퍼즐에서 숫자와 기호를 발굴하고, 문장에 맞는 수식을 완성해 탐험의 길을 여는 Android 게임입니다. 기존 KVM을 Flutter/Dart로 재구성했습니다. 현재 계산의 평원(R1) 60개 스테이지를 플레이할 수 있으며, R2~R7은 `업데이트 예정`으로 닫혀 있습니다.

이번 v0.1.4를 새 시작 기준으로 삼아 저장 epoch `expedition-1`을 적용했습니다. v0.1.3 이하의 진행은 이어 읽지 않고 캐릭터 선택과 필수 튜토리얼부터 시작합니다. 이전 저장 원본·미디어는 물리적으로 삭제하지 않으며 이후 일반 업데이트에는 같은 epoch를 유지해 이번 버전부터의 진행을 보존합니다.

v0.1.3은 시작 로딩 중 이번 업데이트를 안내할 수 있습니다. v0.1.2 이하에는 앱 내 업데이트가 없어 위 APK를 직접 설치합니다. 미디어 팩이 v3로 바뀌었으므로 신규 설치·이전 버전 업데이트 모두 이번 전체 APK를 사용합니다.

이 배포는 실기기 테스트를 위한 공개 **알파 사전 릴리스**입니다. 개발용 서명으로 직접 설치할 수 있지만 정식 배포용 키나 Google Play 배포본이 아닙니다. 이후 같은 `com.crus7230.kvm.renewal` 앱을 업데이트할 때에는 같은 서명과 증가한 versionCode가 필요합니다. 설치 오류가 나면 보안 검사 전체를 끄거나 앱 데이터를 삭제하지 말고 오류 문구를 [Issues](https://github.com/Crus7230/kv-engpzl/issues)에 알려주세요.

## v0.1.4 변경 사항

- 최초 한 번 26명 중 플레이어 캐릭터를 선택하고 실제 C01 S01 튜토리얼을 완료해야 모험을 출발합니다. 종료 후에는 선택·보드·식 또는 출발 단계부터 이어집니다.
- R1의 6개 탐험 목적지와 챕터별 경로, 안개·해금·다음 추천·선택 캐릭터 표시를 연결했습니다. 기존 복원 24곳은 길·거점·이정표를 여는 탐험 진행으로 전환했습니다.
- C01 S10에서 D/J, C03 S10에서 L, C05 S10에서 U가 합류합니다. 플레이어로 고른 동료는 중복 구출하지 않습니다.
- 동료 탭은 기존 앱의 26명 프로필·이미지를 승계하고 확보한 동료 정보를 보여줍니다. R1 지도 배경과 D/J 아트를 개선했습니다.
- 기존 아이콘·시작 화면과 보석 교환→제거→낙하·보충→연쇄 모션, 스와이프와 모션 감소 설정을 유지합니다.
- 앱 시작 시 GitHub의 공개 릴리스 목록을 최대 5초 확인합니다. 오프라인·시간 초과·조회 실패 시 기존 게임을 계속 사용할 수 있습니다.
- 새 APK가 있으면 다운로드 또는 나중에 계속하기를 선택합니다. 크기·SHA256·패키지·버전·현재 설치 앱과 같은 인증서를 확인한 뒤 Android 설치 화면을 엽니다. 업데이트 모듈 자체는 진행·미디어를 변경하지 않으며, 이번 초기화는 별도로 승인된 앱 저장 epoch 변경입니다.
- Android가 설치 허용을 요구하면 앱의 `설치 허용 설정`을 열고, 허용 후 돌아와 `설치 다시 열기`를 누릅니다. 무인 설치나 강제 업데이트가 아니며 취소할 수 있습니다.

자동 업데이트는 이 공개 APK 배포용입니다. 향후 Google Play 배포는 해당 정책과 업데이트 방식에 맞게 별도 검토해야 합니다.

## 플레이 흐름

`캐릭터 선택 → 필수 첫 문제 → 출발 → 월드맵·R1 탐험 지도 → 복습 또는 다음 스테이지 → 매치·발굴 → 수식 완성·해설 → 탐험 이정표·동료 합류 → 다음 추천`

- R1은 6챕터 × 10개 스테이지입니다. 기본 연산, 혼합 연산·괄호, 복습, 보드 효과 학습과 전이 문제로 이어집니다.
- 수학 풀이와 매치 퍼즐과 지도 진행은 별도 모델로 연결합니다. 매치만 하거나 숫자만 모아서는 완료되지 않습니다.
- 3단계 힌트, 오개념 피드백과 풀이 해설을 제공합니다. 힌트를 사용해도 다음 스테이지와 복원 보상은 막지 않습니다.
- 도래한 복습과 다음 탐험을 추천합니다. 빠진 날짜를 벌주거나 연속 출석을 초기화하지 않습니다.
- 탐험 이정표는 24곳입니다. 챕터 진행으로 R1 동료를 확보하고, 확보한 동료의 프로필·합류 이야기를 다시 볼 수 있습니다.
- 중단한 보드와 작성 중인 식, 진행과 복원을 저장합니다. 첫 완료 보상은 중복 지급하지 않습니다.
- 광고, 결제, 가챠, 생명과 대기시간은 없습니다. 인터넷 연결 없이 기본 플레이를 할 수 있습니다.

진행 구조는 꿈의 정원(Gardenscapes)의 퍼즐·정원 분리를 장르 참고점으로 삼았습니다. 기존 KVM의 세계관·캐릭터와 인접 교환 퍼즐을 유지합니다.

## 검증 범위와 알려진 제한

탐험 구현은 `flutter analyze --no-pub` 오류 0건과 전체 Flutter 테스트 360개를 통과했습니다. 필수 튜토리얼·승인된 초기화·단계별 중단 복원·뒤로 가기·동료 합류와 중복 방지·이야기 큐, R1 60개 연속 완료·다음 날 복습·저높이 화면을 자동 검증했습니다. v0.1.4 Android 전체 APK 빌드와 APK v2 서명, v0.1.3과 같은 인증서, 실제 버전·패키지·minSdk, 미디어 31개의 크기·SHA256을 확인했습니다.

실제 Android 휴대폰의 설치·앱 내 APK 다운로드·설치 확인·강제 종료 복원·성능과 전체 APK에서 로직 전용 APK로의 업데이트는 아직 검증하지 않았습니다. 웹·Flutter viewport 캡처는 실제 기기 검증이 아닙니다. 아트·스토리 확장과 사람 플레이에 따른 난도 보정은 계속 개발합니다. 학습 성취 향상은 실제 사용자 연구로 확인한 결과가 아닙니다.

오류를 제보할 때는 기종, Android 버전, 앱 버전, 스테이지 ID, 재현 순서와 화면을 알려주세요. 개인정보나 기기 식별자를 포함할 필요는 없습니다.

## 에셋과 향후 업데이트

이번 다운로드는 신규 설치와 이전 미디어 팩 업데이트에 필요한 **전체 APK**입니다. 최초 실행 시 검증한 `r1-media-v3` 이미지 31개를 앱 전용 저장소에 보존합니다. 이후 같은 미디어를 쓰는 로직 전용 APK가 이를 재사용하는 구조입니다. 로직 수정도 APK 업데이트이며 원격 Dart 코드 패치가 아닙니다.

로직 전용 배포에는 같은 application ID·서명, 증가한 versionCode가 필요합니다. 앱 삭제·데이터 초기화·새 기기와 새 미디어 팩에는 전체 APK가 필요합니다. 실제 업데이트 전환을 검증하기 전에는 로직 전용 APK를 신규 사용자에게 제공하지 않습니다. 정식 키로 전환할 때의 설치·진행 이전 정책은 별도로 확정해야 합니다.

[R1 구현과 검증 상세](docs/R1_COMPLETE_ALPHA_IMPLEMENTATION.md), [에셋 분리와 업데이트](docs/ASSET_PACK_UPDATES.md), [학습·복습 설계](docs/LEARNING_PROGRESSION_DESIGN.md), [7리전 커리큘럼](docs/REGIONAL_STAGE_CURRICULUM.md)을 참고하세요. 이전 단계의 문서는 당시 구현과 검증 기록이며 이번 APK 배포 상태는 이 README와 해당 Release 안내를 기준으로 합니다.

### 이후 APK 게시 계약

업데이트 조회는 알파도 포함하는 공개 `/releases?per_page=20` 목록을 사용합니다. 초안과 잘못된 메타데이터는 무시합니다. 현재 R1 채널은 `vX.Y.Z-r1-alpha` 또는 `vX.Y.Z` 태그와 `KVM-R1-X.Y.Z-alpha.apk` 전체 APK를 사용합니다. 릴리스 본문에 다음 형식의 한 줄을 넣고 실제 APK와 versionCode를 일치시켜야 합니다.

```html
<!-- kvm-update: {"schema":1,"versionName":"0.1.4","versionCode":5} -->
```

다음 버전에서는 값과 파일명을 함께 변경하고 versionCode를 반드시 증가시킵니다. APK 하나를 첨부하고 GitHub asset의 크기·SHA256 digest, 공개 다운로드와 설치 서명을 검증한 뒤 공개합니다. 현재 앱 버전과 같거나 오래된 버전은 안내하지 않습니다.
